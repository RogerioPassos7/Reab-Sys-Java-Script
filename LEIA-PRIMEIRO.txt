ReabSYS - como abrir o projeto no SEU computador

1. Baixe ReabSYS-JavaScript.zip.
2. Clique com o botao direito no ZIP e escolha Extrair tudo.
   Nao execute os arquivos de dentro do ZIP sem extrair.
3. Abra a pasta extraida ReabSYS-JavaScript.

OPCAO MAIS PRATICA NO WINDOWS (precisa de Python 3)

De dois cliques em INICIAR-WINDOWS.bat.
O navegador deve abrir sozinho. Mantenha a janela do terminal aberta.
Se nao abrir, copie o endereco que o terminal mostrar para o navegador.
Para encerrar, volte ao terminal e pressione Ctrl+C.
Se faltar Python, baixe pelo site oficial https://www.python.org/downloads/.

ALTERNATIVA PELO VS CODE

1. Abra a pasta extraida inteira no VS Code (Arquivo > Abrir Pasta).
2. Instale a extensao Live Server, de Ritwick Dey, se ainda nao tiver.
3. Clique com o botao direito em frontend/index.html.
4. Escolha Open with Live Server.

LINUX, MAC OU TERMINAL

Abra um terminal dentro da pasta extraida e execute:
python3 iniciar.py

No Windows, voce tambem pode executar:
py -3 iniciar.py

COMO USAR

Na pagina inicial, clique em Comecar agora e em Entrar na demonstracao.
No menu, navegue entre Visao geral, Pacientes e Agenda.
Use apenas dados ficticios. Nao e necessario informar senha.
Nao precisa instalar npm, Angular, Java ou banco de dados.

SE ALGO NAO ABRIR

- Confira se extraiu a pasta inteira, incluindo frontend/assets/images.
- O endereco localhost so funciona no computador que esta executando o servidor.
- Deixe o terminal ou o Live Server ligado enquanto usa as paginas.
- Nao abra apenas um HTML isolado nem mova os arquivos para pastas diferentes.
- Se os registros parecerem diferentes, use sempre o mesmo endereco e porta.
- Informe o sistema operacional e copie a mensagem de erro para pedir ajuda.
